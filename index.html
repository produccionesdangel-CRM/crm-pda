Novedades en esta versión (v3.7.1)

Corrección del guardado y edición
Se corrigió un bug que impedía guardar nuevos clientes y editar los existentes. Ahora el formulario CRUD funciona correctamente para todas las entidades (clientes, paquetes, servicios). Se eliminó código duplicado y se reorganizó la lógica de listeners para evitar conflictos.
Comprobantes de pago con huella única
Cada pago genera una huella de 15 dígitos y un comprobante en imagen listo para enviar por WhatsApp o Email.
