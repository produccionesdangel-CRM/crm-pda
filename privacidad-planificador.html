Política de privacidad — Planificador JFR Media

Última actualización: 18 de octubre de 2026

Planificador JFR Media es una aplicación de escritorio que corre en la computadora del propio usuario y sirve para programar y publicar su contenido de video en sus propias cuentas de redes sociales (Facebook, Instagram, YouTube y TikTok).

1. Qué datos trata la aplicación

  • Los videos e imágenes del usuario: se leen del disco de la propia computadora y se envían únicamente a la red social que el usuario elige publicar. No se copian a ningún servidor del desarrollador: la aplicación no tiene servidor propio.
  • Datos de la cuenta conectada: cuando el usuario autoriza una red social, la aplicación recibe los permisos que la red concede (por ejemplo el nombre y la foto de perfil, o el identificador de la cuenta) y los tokens de acceso necesarios para publicar.
  • La programación del contenido: fechas, horas, títulos y descripciones que el usuario escribe.

2. Dónde se guarda todo

Todo se guarda en la computadora del usuario, en la carpeta data del programa. Los tokens de acceso se guardan en el archivo data/conexiones.json. No hay nube, ni base de datos, ni servidores del desarrollador.

3. Para qué se usa

  • Publicar el contenido que el usuario programó, en las fechas y horas que él eligió.
  • Mostrar el estado de las publicaciones (pendiente, publicada o con error).
  • Mostrar estadísticas propias de las cuentas del usuario, cuando la red social lo permite.

4. Qué NO hace la aplicación

  • No publica en cuentas de terceras personas: sólo en las cuentas que el usuario autoriza expresamente.
  • No vende, alquila ni comparte datos con nadie.
  • No usa analítica, rastreadores ni publicidad.
  • No lee mensajes privados ni datos de otros usuarios de las redes sociales.

5. Con quién se comparte

Sólo con la red social que el usuario elige: los videos y los textos se envían a través de las interfaces oficiales (APIs) de Facebook/Meta, Google/YouTube y TikTok, aplicando las políticas de privacidad de cada una de esas plataformas.

6. Cuánto tiempo se guarda

Mientras el usuario no borre los datos. El usuario puede desconectar una cuenta desde la propia aplicación (botón Desconectar), lo que elimina los tokens guardados, o borrar la carpeta data para eliminar todo.

7. Derechos y contacto

Para solicitar el acceso, la corrección o la eliminación de cualquier dato, o para preguntar cualquier cosa sobre esta política, escribe a: produccionesdangel@gmail.com. Si la solicitud se refiere a datos de una red social concreta, también se puede revocar el permiso desde la configuración de esa red social.
